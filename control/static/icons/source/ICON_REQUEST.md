# Iconfont SVG 清单

来源：Iconfont「24x24 网格线性图标字体集（长期补充更新）」

请下载 SVG 格式，保持 24×24 视框，按下列英文文件名保存到本目录。优先选择线性图标；`play-filled.svg` 可选同系列实心版本。

## 必需

- `speaker.svg`：音箱 / 设备
- `queue.svg`：播放队列 / 音乐列表
- `playlist.svg`：歌单
- `library.svg`：曲库 / 音乐
- `play.svg`：播放（线性）
- `play-filled.svg`：播放（实心）
- `pause.svg`：暂停
- `stop.svg`：停止
- `previous.svg`：上一首
- `next.svg`：下一首
- `volume.svg`：音量
- `mute.svg`：静音
- `repeat.svg`：循环
- `repeat-one.svg`：单曲循环
- `shuffle.svg`：随机
- `search.svg`：搜索
- `refresh.svg`：刷新
- `import.svg`：导入 / 上传
- `export.svg`：导出 / 下载
- `trash.svg`：删除
- `drag.svg`：拖拽排序
- `folder.svg`：文件夹
- `album.svg`：专辑 / 唱片
- `artist.svg`：歌手 / 用户
- `track.svg`：曲目 / 音符
- `more.svg`：更多（三点）
- `plus.svg`：增加
- `minus.svg`：减少
- `reset.svg`：归零 / 重置（圆形箭头）
- `close.svg`：关闭
- `back.svg`：返回 / 左箭头
- `chevron-right.svg`：进入详情
- `expand.svg`：展开播放器
- `collapse.svg`：收起播放器

## 可选

- `airplay.svg`：AirPlay / 投屏
- `cast.svg`：DLNA / 投送
- `network.svg`：网络音源
- `lyrics.svg`：歌词 / 文本
- `save.svg`：保存
- `edit.svg`：重命名 / 编辑
- `menu.svg`：移动端菜单
- `check.svg`：完成 / 已连接

不用修改 SVG 内容，也不用打包字体。下载完成后直接通知 Codex；构建阶段会统一清理颜色、尺寸并合并为本地 SVG Sprite。
